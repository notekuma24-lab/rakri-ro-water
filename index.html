पहले Firebase कॉन्फ़िगरेशन भरें

यह सुरक्षित starter है। नीचे दिए गए निर्देशों के अनुसार Firebase Web App की कॉन्फ़िगरेशन जानकारी को इस फाइल में भरने के बाद ही लॉगिन चालू होगा। इस फाइल को सार्वजनिक करने से पहले Firestore Rules भी प्रकाशित करें।

Firebase Console → Project settings → Your apps → SDK setup and configuration में अपनी Web App config देखें। Firebase API key सामान्यतः वेब कॉन्फ़िगरेशन का हिस्सा होती है; सुरक्षा Firestore Rules और Authentication से लागू होती है। Service account key कभी भी यहाँ न डालें।
